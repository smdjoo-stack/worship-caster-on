# 예배송출 (Worship Caster)

찬양 가사·성경·광고·악보·사진·영상을 **예배당 TV**, **프롬프터**, **유튜브 방송(OBS) 자막**에 한꺼번에 내보내는 교회용 송출 프로그램입니다.
윈도우와 맥에서 동작합니다.

원작: 쉬운목사 이광복 (예배송출 v0.3.1, "무료로 나눕니다"). 이 저장소는 원작에 기능을 더한 버전입니다.
무엇을 바꾸었는지는 [CHANGELOG.md](CHANGELOG.md)에 정리했습니다.

## 내려받아 쓰기

[Releases](../../releases)에서 완성된 파일을 받으세요.

- **윈도우**: `worship-caster-windows.zip` 압축을 풀고 `예배송출 실행.cmd` 실행
- **맥**: `worship-caster-mac.zip` 압축을 풀고 `예배송출.app`을 응용 프로그램 폴더로 옮긴 뒤 실행
  (처음 한 번: 시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기])

## 주요 기능

| 기능 | 내용 |
| --- | --- |
| 송출 조작 | 이전·다음, 검은화면(B), 글자 지우기(C), 로고(L), 모두 끄기(Esc), 방송 자막 끄기(O) |
| 미디어 배경 | 미디어 칸의 사진·영상을 누르면 예배당 화면 배경으로 계속 재생. 맞춤(자동·꽉 채우기·전체 보이기·작게), 방송(OBS)에도 내보내기 |
| 방송 자막(OBS) | 자막 위치·바 불투명도·곡명 표시, 악보·사진을 방송에 화면 가득 또는 화면 일부(위치 6곳)로 |
| 프롬프터 | 예배당 화면과 똑같이 표시 |
| 자료 | 찬양(가사 가져오기), 성경, 광고, PPT, PDF·악보, HTML 슬라이드 |
| 웹 편집기 | 같은 네트워크의 다른 컴퓨터에서 PIN으로 접속해 주중에 자료 준비 |
| 종료 | 예배당 화면·프롬프터·운영 화면 창이 함께 닫힘 |
| 우리 교회 로고 | ⚙︎ 설정 → 타이틀 로고: 운영 화면 맨 위에 교회 로고 (기본 ✝). 로고(L 키)도 설정에서 고름 |

## 폴더 구성

```
app/       서버(server.js)와 화면(public/) — 윈도우·맥 공통
windows/   윈도우 실행 파일과 사용법
mac/       맥 앱 실행기(launcher)·Info.plist·아이콘·처음 실행 방법
```

## 직접 실행 (개발)

Node.js 18 이상이 필요합니다.

```bash
cd app
npm install
node server.js
```

브라우저에서 `http://localhost:5300/control` 이 운영 화면입니다.

- 예배당 화면 `http://localhost:5300/output`
- 프롬프터 `http://localhost:5300/stage`
- OBS 자막 `http://<이 컴퓨터 IP>:5300/overlay` (브라우저 소스 1920×1080)

자료(예배 순서·찬양·미디어)는 윈도우 `%APPDATA%\WorshipCaster`, 맥 `~/Library/Application Support/WorshipCaster` 에 저장됩니다.
이 저장소에는 성경 본문 파일과 교회 자료는 들어 있지 않습니다.
